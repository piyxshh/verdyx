Module 1: Foundational Architecture & Invariant Guarantees

Modern enterprise decision intelligence requires combining quantitative statistical predictions with qualitative natural-language reasoning. However, naive implementations that rely on Large Language Models (LLMs) to estimate numerical risks fail catastrophically in high-stakes enterprise deployments.

1.1 Why Pure LLM Financial Risk Estimation Fails

When a prompt containing financial balance sheet ratios is passed to an LLM with the instruction "Estimate the bankruptcy probability of this company," several fundamental flaws occur:

  • Non-Deterministic Variance: LLMs sample tokens probabilistically. Asking the exact same prompt twice can yield 62% in execution A and 78% in execution B.
  • Lack of Empirical Calibration: LLMs are trained on text corpora to predict the next word, not on numerical optimization functions. They possess no mathematical model of feature covariance or empirical cumulative density functions.
  • Hallucinated Confidence: An LLM will confidently assert numbers based on linguistic patterns (e.g. "debt ratio of 0.6 sounds high, so probability is 80%") without knowing the underlying dataset's decision boundaries.
💎 The Invariant Architectural Rule of Verdyx

Prediction is architecturally prior to interpretation.

In Verdyx, no Large Language Model or agent prompt is ever permitted to calculate, estimate, or alter the financial distress probability score. The distress probability $P(\text{Distress} \mid X)$ is calculated first by a trained RandomForestClassifier on verified empirical dataset features. All downstream agents receive this probability as an immutable, established fact and focus 100% of their compute on qualitative explanation, domain decomposition, and stress-testing.

Module 2: Machine Learning Deep Dive — From First Principles

This section provides a rigorous, textbook-level explanation of the Machine Learning model powering Verdyx, designed so that even a complete beginner can understand every mathematical and statistical decision.

2.1 Taiwanese Bankruptcy Dataset Provenance & Structure

The dataset used to train Verdyx is the Taiwanese Bankruptcy Prediction Dataset hosted on the canonical UCI Machine Learning Repository (CC BY 4.0 License). It was collected by the Taiwan Economic Journal from 1999 to 2009 based on Stock Exchange business regulations.

Mathematical Formulation of the Input Matrix:

The dataset is a numerical matrix $X \in \mathbb{R}^{6819 \times 95}$ and a binary target vector $y \in \{0, 1\}^{6819}$:

X = \begin{bmatrix} x_{1,1} & x_{1,2} & \dots & x_{1,95} \\ x_{2,1} & x_{2,2} & \dots & x_{2,95} \\ \vdots & \vdots & \ddots & \vdots \\ x_{6819,1} & x_{6819,2} & \dots & x_{6819,95} \end{bmatrix}, \quad y = \begin{bmatrix} y_1 \\ y_2 \\ \vdots \\ y_{6819} \end{bmatrix}
Variable Data Type Description & Range
Sample Count (N) Integer 6,819 companies evaluated over 10 operational years.
Features (p) Continuous Float 95 financial ratio variables normalized between [0.0, 1.0].
Target (y) Binary Integer 0 = Solvent / Healthy (6,599 instances)
1 = Bankrupt / Distressed (220 instances)
2.2 Single Decision Tree Mechanics & Gini Impurity

A Decision Tree partitions the 95-dimensional feature space into rectangular regions by finding optimal threshold splits $x_j > \theta$.

Mathematical Split Criterion — Gini Impurity:

At any node $t$, the Gini Impurity measures the probability of misclassifying a randomly chosen element if it were randomly labeled according to the distribution of targets in the node:

I_G(t) = 1 - \sum_{k=0}^{1} p_k^2 = 1 - (p_0^2 + p_1^2)

Where $p_0$ is the proportion of solvent companies in node $t$, and $p_1$ is the proportion of bankrupt companies.

  • Pure Node ($I_G = 0$): All samples in the node belong to a single class (e.g. 100% healthy or 100% bankrupt).
  • Maximal Impurity ($I_G = 0.5$): Samples are evenly split 50/50 between classes.
  • Information Gain Maximization: The tree selects feature $j$ and split threshold $\theta$ that maximizes the drop in impurity $\Delta I_G = I_G(parent) - \left(\frac{N_{left}}{N} I_G(left) + \frac{N_{right}}{N} I_G(right)\right)$.
2.3 Random Forest Ensembles (Bagging & Feature Subsampling)

A single decision tree is high-variance and prone to overfitting. A Random Forest mitigates this by constructing an ensemble of $B = 200$ decorrelated decision trees.

1. Bootstrap Aggregating (Bagging)

Each of the 200 trees is trained on a bootstrap sample of $N = 6,819$ records drawn with replacement from the original dataset. On average, each tree sees ~63.2% of unique samples, while the remaining 36.8% form the Out-Of-Bag (OOB) validation set.

2. Random Subspace Feature Selection

At every node split, the algorithm is restricted to choosing from a random subset of $m = \sqrt{p} = \sqrt{95} \approx 9$ features rather than all 95. This prevents dominant features from making all 200 trees identical, ensuring high ensemble diversity.

Probability Estimation Function predict_proba():

For a new input vector $x$, each tree $b \in \{1, \dots, 200\}$ outputs a probability distribution $p_b(y=1 \mid x)$. The final distress probability is the ensemble average across all 200 trees:

P(\text{Bankrupt} \mid x) = \frac{1}{200} \sum_{b=1}^{200} p_b(y=1 \mid x)
2.4 The Severe Class Imbalance & Evaluation Metrics

Only 220 out of 6,819 companies (3.23%) in the dataset are bankrupt.

⚠️ The Accuracy Trap (Crucial for Enterprise Production)

A dummy classifier that outputs 0 (Solvent) for every company achieves 96.77% raw accuracy while missing 100% of bankrupt companies! Accuracy is a fundamentally misleading metric for rare event detection.

How We Solved Class Imbalance:

We passed class_weight='balanced' to RandomForestClassifier. This automatically calculates weights inversely proportional to class frequencies:

w_k = \frac{N}{2 \cdot N_k} \implies w_0 = \frac{6819}{2 \times 6599} \approx 0.516, \quad w_1 = \frac{6819}{2 \times 220} \approx 15.498

Misclassifying a bankrupt company penalizes the model ~30 times more heavily than misclassifying a solvent company!

2.5 Gini Feature Importance (Mean Decrease in Impurity)

Random Forest calculates the global Gini Feature Importance $I(X_j)$ for every feature $X_j$ by summing the impurity decreases $\Delta I_G$ across all nodes where $X_j$ was selected for splitting:

I(X_j) = \frac{1}{B} \sum_{b=1}^{B} \sum_{t \in T_b : v(t) = j} p(t) \Delta I_G(t, j)

2.6 Median Imputation Strategy (Filling 85 Unexposed Features)

The frontend form exposes only the Top 10 financial ratios to minimize cognitive load on users. However, the trained Random Forest requires a complete 95-dimensional input vector $\vec{x} \in \mathbb{R}^{95}$.

🎯 Why Dataset Medians?

During training, we pre-calculated the median value $\tilde{x}_j = \text{median}(\{x_{i,j}\}_{i=1}^N)$ for all 95 features across the 6,819 training records and exported them to ml/models/feature_medians.json.

At inference time, the predictor starts with a 95-dimensional vector where every feature is set to its dataset median. It then overwrites the 10 user-provided ratios. The median represents the statistical center of the dataset — substituting median values introduces zero artificial bias toward either health or bankruptcy!

Module 4: LangGraph Orchestration & Multi-Agent Specifications

LangGraph controls the execution sequence and state mutations across all 5 nodes:

💰
1. Finance Agent
Solvency & Debt Specialist

Routed Inputs: Borrowing dependency, Total debt/Total net worth, Debt ratio %, Retained Earnings to Total Assets.

Prompt Constraint: "The probability of 71.4% is a fixed statistical fact. Explain why high debt dependency creates capital fragility."

📈
2. Market Agent
Operations & ROA Specialist

Routed Inputs: Persistent EPS in Last 4 Seasons, Net Income to Total Assets (ROA), Pre-tax profit / Paid-in capital.

Prompt Constraint: "Explain how trailing earnings erosion and sub-median return on assets impair operational recovery."

⚡
3. Risk Agent
Compound Failure Detector

Routed Inputs: Full 95-ratio context + finance_report + market_report.

Job: Identifies non-linear compound vulnerabilities (e.g. "High leverage + earnings decay = inability to absorb cash flow shocks").

⚖️
4. Decision Agent
Structured Verdict Synthesizer

Routed Inputs: Probability + All 3 Agent Reports. Emits structured JSON: 

{
  "risk_tier": "High Risk",
  "confidence": 0.88,
  "reasoning": "High debt dependency combined with multi-quarter earnings erosion creates acute insolvency risk."
}
